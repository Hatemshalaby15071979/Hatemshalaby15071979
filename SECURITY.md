# Security Policy

## Supported Versions

This repository is the owner's **GitHub profile README**. It contains no
executable code, runtime services, or versioned releases to patch.
Security-relevant content (the profile README and repository configuration)
is treated as current at all times.

| Version            | Supported          |
| ------------------ | ------------------ |
| Latest (`master`)  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue in this repository — for example, accidentally
committed credentials, API keys, or personally identifiable information in this
**public** repository's history — please **do not open a public issue**.

Report it privately using GitHub's built-in reporting flow:

1. Open this repository's **Security** tab.
2. Click **Report a vulnerability** (GitHub Security Advisories / private
   vulnerability reporting).
3. Describe the issue, the affected content, and any steps to reproduce.

This uses GitHub's private vulnerability reporting — **no email address is
required**.

## Response Times

| Step                                  | Target                |
| ------------------------------------- | --------------------- |
| Initial acknowledgement               | within 72 hours       |
| Triage & severity assessment          | within 7 days         |
| Remediation (remove exposed content)  | as soon as verified, typically within 14 days |

You will receive updates on the reported advisory as it is triaged and resolved.

## Scope

**In scope**
- Accidentally committed secrets, tokens, or personally identifiable
  information in this repository's public history.
- Misconfiguration of this repository's security settings.

**Out of scope**
- Vulnerabilities in third-party projects, services, or dependencies that this
  profile merely links to or mentions.
- General GitHub account security (use GitHub's account recovery and
  two-factor authentication settings).
